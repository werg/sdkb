# Stored confirmation of cross-world routing supervision

Freeze both 800-update router continuations before creating 32 new worlds. Compare
matched within-world versus global-negative training using the same long-trained
MLP, unchanged payload writer/reader/decoder and frozen one/two-record classifier.
Only stored address keys and the independent routing projection differ.

Build separate banks offline with the frozen writer and verified adapter identity,
then disable writer/compactor for every read. For each arm test supplied world
scope and the entire 128-record bank. Keep oracle supports, no memory, captured-plan
zero values and candidate-free first-eight-world generation (24 new tokens).
Require identical raw payload/provenance rows across arms and identical oracle /
no-memory scores. Pair by question/world; distinguish required-pair retrieval,
choice accuracy, and free generated answers. This remains a small synthetic bank,
not ANN, a general agent benchmark or evidence of parameter substitution.

All banks, generation rows and two small completed routing states stay external.
No new full-model checkpoints are created. Endpoint and dataset hashes freeze the
comparison, and completed pool reports remain reusable after interruption.

Counterfactual follow-up: build separate permission/restoration-flipped banks with
source IDs, causal queries and provenance preserved. Replay the original full-bank
learned selections, without reranking after payload changes. On all 128 action
questions report both-correct changed pairs and false changes on invariant pairs;
also generate counterfactual action strings on the original first-eight-world
subset. This isolates sensitivity to retrieved values, not an end-to-end changed-key
retrieval score. Run both continuations without selecting the better ordinary arm.

After ordinary results, the first-eight-world subset gives 17/32 generated global
arm actions versus 15/32 control, while whole-corpus choice results are 80/128
versus 55/128. Choice and free predictions agree on every sampled action, suggesting
subset composition rather than a decoding discrepancy. Extend candidate-free action
generation and counterfactual pairs to all 32 worlds, for both frozen arms, keeping
the original smaller result intact and checking every previously generated row.
This is a post-result measurement expansion, with no training or endpoint selection.

## Completed stored confirmation and expanded generation

All 128 raw payload/provenance rows and all 640 oracle/no-memory score rows per
pool agree exactly between arms. Under full-bank competition, global versus world
negative training yields 80/128 versus 55/128 action choices, a paired gain of
19.53 points [4.69, 33.59]. Complete action-pair retrieval is 38/128 versus 5/128.
Under supplied-world scope, action choices are 102/128 versus 110/128; the paired
interval includes zero, and the global objective does not dominate every metric.

Expanding candidate-free actions to all worlds gives exactly the same 80/128
versus 55/128. Every one of the 128 previously generated action/control rows per
arm reproduces exactly. Global zero/no-memory controls score 64/128 and 65/128;
raw oracle scores 128/128. Global-minus-zero free action gain is 12.50 points
[0.78, 24.22]; global-minus-none is 11.72 [0, 22.66]. These are one training seed,
one small bank and uncorrected world-bootstrap diagnostic intervals.

With captured original global read plans, candidate-free permission-change pairs
have both answers correct for 52/128 global versus 24/128 world. Restoration-change
pairs score 25/64 versus 12/64; invariant restoration answers falsely change for
14/64 versus 21/64. Choice and generated counterfactual results agree on the full
action grid. Cross-world training makes some stored evidence useful, but global
composition and conditional behavior remain unreliable. This is not an agent or
parameter-substitution result.
